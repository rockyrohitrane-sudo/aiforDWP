# Copilot Prompting Starter Guide (FinBridge)

This guide is for everyday office tasks. No technical terms, no theory overload. Just practical prompts you can copy, tweak, and use today.

## What makes a good prompt?

Use this simple formula:

**Task + Context + Output + Tone + Check**

Think of it as: **"What you want" + "what Copilot should know" + "what the result should look like" + "how it should sound" + "what to double-check"**.

### Quick template

Copy this and fill in the blanks:

> "Help me [task]. Context: [key details]. Output: [format/length]. Tone: [friendly/formal/concise]. Check: [accuracy, dates, names, action items]."

### Why this works

- Task: tells Copilot the job.
- Context: avoids generic output.
- Output: gives a clear shape (email, table, bullets, summary).
- Tone: makes it usable straight away.
- Check: reduces mistakes before sending.

## Outlook prompts (email and calendar)

### 1) Draft a client-ready follow-up email

> "Draft a follow-up email to a client after today’s call about pension transfer timelines. Include: recap of agreed actions, expected next date, and a polite request for missing ID documents. Keep it professional, clear, and under 170 words. End with a short action summary."

### 2) Triage a busy inbox

> "Review today’s inbox and sort emails into three groups: Urgent Today, This Week, and For Information. For each urgent email, suggest a short reply I can send now and one follow-up task to add to my to-do list."

### 3) Prepare for a meeting from email history

> "Using this week’s email thread with the Finance Ops team, create simple meeting prep notes with: decisions already made, open questions, who is doing what, and due dates. Format as bullet points I can paste into my meeting notes."

## Word prompts (documents, notes, and reports)

### 1) Turn rough notes into a clean summary

> "Turn these meeting notes into a 1-page summary with headings: Objective, Key Decisions, Risks, Actions, and Next Steps. Keep plain business language and include an action table with Owner and Due Date columns."

### 2) Rewrite for clearer business tone

> "Rewrite this draft update for senior managers. Keep all facts the same, remove jargon, and make it easier to scan. Use short paragraphs and bullet points. Target length: 250-300 words."

### 3) Create first draft of a policy communication

> "Draft a staff communication for a change to month-end reporting deadlines. Include: what is changing, when it starts, who is affected, what teams must do now, and where to ask questions. Tone should be supportive and direct."

## Excel prompts (analysis and data cleanup)

### 1) Explain trends in plain language

> "Look at this monthly complaints table and summarize: where numbers have gone up the most since last month, possible reasons, and anything unusual. Then suggest 3 practical actions for next month. Keep it simple and non-technical."

### 2) Help clean inconsistent data

> "Check this sheet for category names that are written in different ways (for example, two spellings for the same category), important empty cells, and duplicate rows. List what needs fixing first and the order to do it."

### 3) Build a useful summary view

> "Create a summary of this workbook showing total cases by team, average time to resolve, and the percentage completed within target time. Present results in a small table and suggest one chart type to share in the weekly ops meeting."

## Prompt upgrade tips (when first result is not quite right)

If the first response is too broad, ask a second prompt like:

- "Make it shorter and more direct."
- "Use bullet points and add owners + dates."
- "Keep the same content but change the tone to client-friendly."
- "Show top 3 priorities first."

A good result often comes from one follow-up prompt, not one perfect first prompt.

## Data safety habit (important)

From Day 1 of this programme: **treat data safety as a daily habit, not a one-off warning**.

- Use approved Microsoft 365 Copilot in your FinBridge environment for work content.
- **Do not paste confidential client data into external AI tools** (public chatbots, unknown browser tools, or unapproved apps).
- If you are unsure whether a tool is approved, stop and check with IT before pasting any client or sensitive business information.

This is a safety habit, not a reason to avoid Copilot. You can use Copilot confidently for day-to-day work in approved FinBridge tools.

When in doubt, remove names, account numbers, and any identifying details first.

## 30-second starter workflow

1. Pick one real task (email, summary, or spreadsheet insight).
2. Use the formula: Task + Context + Output + Tone + Check.
3. Run prompt.
4. Refine once with a follow-up instruction.
5. Review facts before sending or sharing.

That is enough to start using Copilot confidently in daily FinBridge work.
