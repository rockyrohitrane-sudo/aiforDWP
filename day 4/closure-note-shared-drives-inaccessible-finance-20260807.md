# Closure Note - Shared Drives Inaccessible - Finance Users - 2026-08-07

Resolved. Cause: Intune PowerShell script `Map-FinBridgeDrives.ps1` executing as SYSTEM before the Workstation service was available, preventing UNC path `\\finbridge-fs01\Finance` from being mapped at logon — affecting 45 Finance users (DESKTOP-FB*) from ~08:00; root configuration fault introduced by GPO-to-Intune migration on 2024-03-14 where execution context was not updated. Action: Intune portal — `Map-FinBridgeDrives.ps1` property *"Run this script using the logged on credentials"* changed to **Yes**; script re-assigned to Finance device group. Preventive: GPO-to-Intune migration runbook to be updated with mandatory execution context and service dependency verification step before go-live; all Intune scripts accessing network resources under SYSTEM context to be audited and remediated.
